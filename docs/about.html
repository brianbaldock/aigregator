AIGREGATOR is a daily AI news digest, scored and cited. Generated each morning at 0700 Pacific by an autonomous Hermes agent.

HOW IT WORKS

  • Agent scours primary lab blogs, reputable press, social signal, and arXiv every morning.
  • Scores are a ranking heuristic based on assigned source credibility and retained source domains, not a probability that a claim is true.
  • Social discussion stays in Discourse. Repository links discovered on r/BestGitHubRepos can appear in Cool Projects after an explicit AI-fit review, with the discussion attributed separately.
  • Reddit recommendations do not increase news corroboration counts. Multiple domains alone do not prove independent confirmation or that a summary is accurate.

SCORING KEY

  • Base: 2 × credibility, using an assigned credibility weight from 1 to 5.
  • Add 3 per additional retained source domain in a cluster.
  • Add 1 for a Reuters, AP, Bloomberg or WSJ canonical item discovered through wire search.
  • Subtract 3 for an undated single-source cluster, with a floor of zero.
  • Discrete repositories and models use the base score only. There is no eight-point ceiling.

TAGS

  • FIRE: two or more retained source domains in a cluster, not proof of independent confirmation
  • SEEDLING: open-source or non-frontier-lab item
